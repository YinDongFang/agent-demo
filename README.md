






# Install

```bash
pnpm install -g @yindongfang/mini-agent
```

# Run

1. 设置环境变量，命令行设置或写入 .env 文件
```bash
export MODEL_NAME=model
export OPENAI_API_KEY=apikey
export OPENAI_BASE_URL=baseurl
```
2. 运行
```bash
mini-agent
```
